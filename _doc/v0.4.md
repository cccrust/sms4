# SMS4 v0.4 — 私訊功能

在 v0.3 基礎上加入使用者之間的私訊功能，涵蓋資料庫、Model、CLI、Web API 與前端。

## 資料庫擴充

新增 `messages` 表（第 5 張表）：

```sql
CREATE TABLE messages (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    sender_id   INTEGER NOT NULL REFERENCES users(id),
    receiver_id INTEGER NOT NULL REFERENCES users(id),
    content     TEXT NOT NULL,
    read        INTEGER NOT NULL DEFAULT 0,
    created_at  TEXT NOT NULL DEFAULT (datetime('now'))
);
```

- `read` 欄位標記是否已讀（0=未讀, 1=已讀）
- `sender_id` / `receiver_id` 皆為外部鍵參照 `users(id)`
- `created_at` 自動填入目前時間

## Model 層 (`model/message.rs`)

### 結構體

| 名稱 | 用途 |
|------|------|
| `Message` | 原始訊息資料 (id, sender_id, receiver_id, content, read, created_at) |
| `MessageWithUser` | 訊息 + 寄件者與收件者的 username / display_name |
| `Conversation` | 對話摘要 (最後訊息內容、時間、未讀數、對方使用者資訊) |

### 函式

| 函式 | 說明 |
|------|------|
| `send_message` | 發送訊息，回傳新訊息 ID |
| `list_conversations` | 列出使用者的所有對話（GROUP BY 對方 + MAX(id) 取最後一則） |
| `list_messages` | 列出兩使用者間的所有訊息（時間正序） |
| `mark_read` | 將指定對話中所有未讀訊息標為已讀 |
| `get_unread_count` | 取得使用者的未讀總數 |

### conversation 查詢邏輯

- 子查詢以 `CASE WHEN sender_id = ? THEN receiver_id ELSE sender_id END` 分組
- `LEFT JOIN` 子查詢計算各對話未讀數
- 每筆回傳含 `other_user_id`, `other_username`, `other_display_name`, `last_message`, `last_message_at`, `unread_count`

## CLI 指令

```
sms4 msg send <sender_id> <receiver_id> <content>        # 發送私訊
sms4 msg inbox <user_id>                                   # 檢視對話列表（含未讀數）
sms4 msg conversation <user_id> <other_id>                 # 檢視對話內容（自動標為已讀）
```

### 輸出範例

```
對話列表 (未讀 2):
ID    名稱                  未讀        最後訊息                        時間
---------------------------------------------------------------------------------------
2     鮑勃                              明天一起爬山好嗎？              2026-06-13 14:30:00
3     卡蘿                  🔴 1       卡蘿也想爬山！                  2026-06-13 14:31:00
```

## Web API 端點

| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | `/api/messages/send` | 發送私訊 `{sender_id, receiver_id, content}` |
| GET | `/api/messages/{user_id}/conversations` | 對話列表 |
| GET | `/api/messages/{user_id}/{other_id}` | 特定對話內容（自動標已讀） |
| GET | `/api/messages/{user_id}/unread` | 未讀總數 `{"unread": N}` |

### 錯誤處理

- 寄件者或收件者不存在 → 404
- 對話中對方使用者不存在 → 404

## 前端頁面

### Messages (`/messages`)
- 對話列表頁，顯示所有對話與最後一則訊息
- 使用者切換列（快速切換身份）
- 未讀標記（紅點 + 數字）
- 「新訊息」彈窗：選擇使用者開始對話

### Conversation (`/messages/:otherId`)
- 即時對話視窗（3 秒自動輪詢新訊息）
- 訊息氣泡：自己（藍色右側）/ 對方（灰色左側）
- 時間戳顯示
- 底部輸入框 + 送出按鈕
- 自動捲動至最新訊息
- 返回按鈕回到對話列表

### Layout 更新
- 底部導航加入第三項：「私訊」（✉️）
