# SMS4 v1.4 — 社團功能

## 新增功能

### 資料庫
- **groups** 表：name, description, owner_id, member_count
- **group_members** 表：group_id, user_id, role（owner / admin / member）, UNIQUE(group_id, user_id)
- **group_posts** 表：group_id, user_id, content, likes_count

### CLI 指令
```
sms4 group create <user_id> <name> [--description]        # 建立社團
sms4 group list [--search]                                 # 列出社團（可搜尋）
sms4 group mine <user_id>                                  # 我的社團
sms4 group get <id>                                        # 檢視社團
sms4 group update <id> <user_id> [--name] [--description]  # 更新社團
sms4 group delete <id> <user_id>                           # 刪除社團
sms4 group join <group_id> <user_id>                       # 加入社團
sms4 group leave <group_id> <user_id>                      # 退出社團
sms4 group members <group_id>                              # 成員列表
sms4 group post add <group_id> <user_id> <content>         # 社團發文
sms4 group post list <group_id>                            # 社團貼文列表
sms4 group post delete <post_id> <user_id>                 # 刪除貼文
```

### Web API
| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | `/api/groups` | 建立社團 |
| GET | `/api/groups` | 列出社團（支援 `?search=`） |
| GET | `/api/groups/mine?user_id=:id` | 我的社團 |
| GET | `/api/groups/{id}` | 檢視社團 |
| PUT | `/api/groups/{id}` | 更新社團 |
| DELETE | `/api/groups/{id}` | 刪除社團 |
| POST | `/api/groups/{id}/join` | 加入社團 |
| POST | `/api/groups/{id}/leave` | 退出社團 |
| GET | `/api/groups/{id}/members` | 成員列表 |
| POST | `/api/groups/{id}/posts` | 社團發文 |
| GET | `/api/groups/{id}/posts` | 社團貼文列表 |
| DELETE | `/api/groups/{id}/posts/{post_id}` | 刪除貼文 |

### 前端頁面
- **社團列表** (`/groups`) — 探索／我的社團分頁、搜尋、建立社團 Modal
- **社團詳情** (`/groups/:id`) — 社團資訊、貼文串、加入/退出按鈕、成員列表
- **導航列** — 加入「社團」按鈕（6 項導航）

### 權限模型
- 僅社團成員可發文
- 僅創建者或管理員可編輯社團資訊
- 僅創建者可刪除社團
- 作者或創建者可刪除貼文
- 創建者不可退出社團（須刪除）
