# SMS4 v0.3 — React 前端

在 v0.2 Web API 基礎上加入手機優先的 React 前端，支援一體化 Production 部署。

## 新增技術棧

- **前端框架:** React 19 + TypeScript
- **建置工具:** Vite 6
- **CSS:** Tailwind CSS v4 (Utility-first)
- **路由:** react-router-dom v7
- **HTTP 客戶端:** 原生 fetch (無 axios)

## 前端架構

```
web/src/
├── api/client.ts          # API 呼叫封裝
├── components/Layout.tsx   # 底部導航佈局
├── pages/
│   ├── Timeline.tsx        # 社群時間軸 (/)
│   ├── UserList.tsx        # 使用者列表 (/users)
│   ├── UserDetail.tsx      # 使用者個人頁 (/users/:id)
│   └── PostDetail.tsx      # 貼文詳情 (/posts/:id)
├── types/index.ts         # TypeScript 型別
├── App.tsx                # 路由設定
└── main.tsx               # 入口
```

## 頁面說明

### Timeline (`/`)
- 顯示當前使用者與追蹤對象的貼文
- 使用者切換按鈕（單頁多使用者）
- 貼文卡顯示發布者、內容、讚數、回覆數

### UserList (`/users`)
- 列出所有使用者
- 搜尋欄即時過濾

### UserDetail (`/users/:id`)
- 使用者資訊：大頭貼、名稱、簡介、粉絲/追蹤數
- 分頁切換：貼文、回覆、讚過的內容
- 追蹤 / 取消追蹤按鈕

### PostDetail (`/posts/:id`)
- 完整貼文內容
- 按讚 / 取消讚按鈕
- 回覆列表
- 回覆輸入框

## 手機優先設計

- 黑色主題 UI (`bg-black` / `bg-gray-900` / `text-white`)
- 最大寬度 600px 置中，手機下全寬
- 底部固定導航列，仿 Threads 風格（`首頁` / `使用者`）
- Tailwind CSS v4 無任何客製 CSS 檔案

## Production 模式

後端一體伺服 API 與前端靜態檔案：

```
./run.sh prod
```

### SPA 路由處理

- `GET /assets/*` → `ServeDir` 直接回傳靜態資源
- `GET /*` → `fallback(get(...))` 回傳 `web/dist/index.html`
- `resolve_dist_dir()` 自動依 CWD 尋找 `web/dist` 或 `../web/dist`

## 執行方式

```bash
./run.sh dev       # 開發模式 (API + Vite dev server)
./run.sh prod      # Production 模式 (一體伺服)
./run.sh api       # 僅 API 伺服器
./run.sh build     # 僅建置前端
```
