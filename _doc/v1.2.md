# SMS4 v1.2 — 個人商店與商場

## 新增功能

### 資料庫
- **shops** 表：商店（user_id UNIQUE, name, description）
- **products** 表：商品（shop_id, name, price, stock, image, description）
- **orders** 表：訂單（buyer_id, product_id, quantity, total_price, status）

### CLI 指令
```
sms4 shop open <user_id> <name> [--description]
sms4 shop show <user_id>
sms4 shop update <user_id> [--name] [--description]
sms4 shop close <user_id>

sms4 product add <shop_id> <name> <price> [--stock] [--description]
sms4 product list <shop_id>
sms4 product update <id> [--name] [--price] [--stock] [--description]
sms4 product remove <id>
sms4 product search [--q] [--min-price] [--max-price]

sms4 order buy <product_id> <buyer_id> [--quantity]
sms4 order list <user_id>
```

### Web API
| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | `/api/shops/open` | 開店 |
| GET | `/api/shops?user_id=:id` | 查詢自己的商店 |
| GET | `/api/shops/:id` | 檢視商店 |
| PUT | `/api/shops/:id` | 更新商店 |
| POST | `/api/shops/close` | 關店 |
| GET | `/api/products/search?...` | 搜尋商品 |
| GET | `/api/products/shop/:shop_id` | 列出商店商品 |
| POST | `/api/products/shop/:shop_id` | 新增商品 |
| GET | `/api/products/:id` | 檢視商品 |
| PUT | `/api/products/:id/update` | 更新商品 |
| DELETE | `/api/products/:id` | 刪除商品 |
| POST | `/api/orders` | 下單 |
| GET | `/api/orders?user_id=:id` | 訂單列表 |
| GET | `/api/orders/:id?user_id=:id` | 檢視訂單 |

### 前端頁面
- **商場** (`/marketplace`) — 瀏覽所有商店的商品，支援關鍵字與價格搜尋
- **商店頁面** (`/shop/:id`) — 單一商店的商品列表
- **我的商店** (`/my-shop`) — 開店、上架/刪除商品
- **我的訂單** (`/orders`) — 檢視購買記錄

### 導航
底部導航列加入「商場」分頁，使用者名稱旁新增「我的商店」與「我的訂單」連結。
