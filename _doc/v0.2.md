# SMS4 v0.2 — Web Service

在 v0.1 CLI 基礎上加入 RESTful Web API，使用 axum 框架提供 HTTP 介面。

## 新增技術棧

- **Web 框架:** axum
- **非同步執行:** tokio
- **序列化:** serde / serde_json
- **HTTP 伺服器:** Tower (axum 內建)

## 資料庫 (維持 4 張表)

與 v0.1 相同，無結構變動。Web API 直接操作同一 SQLite 資料庫。

## RESTful Web API

所有端點前綴 `/api`，回傳 JSON。

### 使用者

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/users` | 列出使用者 (支援 `?search=`) |
| POST | `/api/users` | 建立使用者 |
| GET | `/api/users/{id}` | 取得單一使用者 (含粉絲/追蹤數) |
| PUT | `/api/users/{id}` | 更新使用者 |
| DELETE | `/api/users/{id}` | 刪除使用者 |

### 貼文

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/posts` | 列出所有原貼文 |
| POST | `/api/posts` | 建立貼文 |
| GET | `/api/posts/{id}` | 取得貼文 (含回覆) |
| DELETE | `/api/posts/{id}` | 刪除貼文 |
| POST | `/api/posts/{id}/reply` | 回覆貼文 |

### 追蹤 & 按讚

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/users/{id}/timeline` | 使用者時間軸 |
| GET | `/api/users/{id}/followers` | 粉絲列表 |
| GET | `/api/users/{id}/following` | 追蹤中列表 |
| POST | `/api/follow` | 追蹤使用者 |
| DELETE | `/api/follow` | 取消追蹤 |
| POST | `/api/likes` | 按讚 |
| DELETE | `/api/likes` | 取消讚 |

### 錯誤處理

- 404: `{"error": "..."}`
- 400: `{"error": "..."}`
- 500: `{"error": "伺服器內部錯誤"}`

### AppState

使用 `Arc<Mutex<Connection>>` 跨執行緒共享 SQLite 連線。

## 執行方式

```bash
cargo run -- web --port 8080              # 啟動 API (dev 模式)
cargo run -- web --port 8080 --dev        # 明確指定 dev 模式
```

## 測試

```bash
cargo test                    # 12 項單元測試
bash case2.sh                 # Web API 整合測試 (41 項)
```
