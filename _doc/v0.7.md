# SMS4 v0.7 — 使用者認證系統

新增註冊/登入/登出功能，使用 bcrypt 密碼雜湊與 token-based session。

---

## 1. 資料庫異動

### users 表新增欄位

| 欄位 | 型態 | 說明 |
|------|------|------|
| `password_hash` | TEXT | bcrypt 雜湊值，可為 NULL（既有使用者） |

### 新增 sessions 表

```sql
CREATE TABLE sessions (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id    INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    token      TEXT UNIQUE NOT NULL,
    created_at TEXT NOT NULL DEFAULT (datetime('now'))
);
```

- Token 使用 UUID v4，作為 API 與 CLI 的登入憑證
- 登出時刪除 token

---

## 2. CLI 指令

```
sms4 auth register <username> <password> [--name <name>]
sms4 auth login <username> <password>
sms4 auth logout <token>
```

| 指令 | 說明 |
|------|------|
| `auth register` | 註冊新使用者，密碼經 bcrypt 雜湊儲存 |
| `auth login` | 驗證帳號密碼，回傳 UUID token |
| `auth logout` | 使 token 失效 |

---

## 3. Web API

| 方法 | 路徑 | Body | 回應 |
|------|------|------|------|
| POST | `/api/auth/register` | `{ username, password, display_name? }` | `{ user }` |
| POST | `/api/auth/login` | `{ username, password }` | `{ token, user }` |
| POST | `/api/auth/logout` | `{ token }` | `{ message }` |
