# SMS4 v0.5 — 交友配對功能（規劃草案）

讓每個人填寫交友基本資訊，其他人可透過這些屬性來搜尋、配對交友對象。

---

## 1. 交友基本資訊屬性

### 資料表設計

新增 `profiles` 表（第 6 張表）儲存交友相關資訊，與 `users` 一對一：

```sql
CREATE TABLE profiles (
    user_id     INTEGER PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
    birthday    TEXT,             -- 生日 YYYY-MM-DD（用於計算年齡區間）
    gender      TEXT,             -- male / female / other
    city        TEXT,             -- 所在城市
    occupation  TEXT,             -- 職業
    education   TEXT,             -- 最高學歷
    height      INTEGER,          -- 身高 (cm)
    looking_for TEXT DEFAULT 'friend',  -- friend / date / any
    about_me    TEXT,             -- 關於我（自我介紹，用於全文檢索）
    updated_at  TEXT NOT NULL DEFAULT (datetime('now'))
);
```

新增 `interests` 表（第 7 張表）支援標籤式興趣搜尋：

```sql
CREATE TABLE interests (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id     INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    tag         TEXT NOT NULL COLLATE NOCASE,
    UNIQUE(user_id, tag)
);

CREATE INDEX idx_interests_tag ON interests(tag);
CREATE INDEX idx_interests_user ON interests(user_id);
```

### 屬性說明

| 屬性 | 型態 | 範例 | 用途 |
|------|------|------|------|
| birthday | TEXT | `1995-03-15` | 計算年齡，支援年齡區間搜尋 |
| gender | TEXT | `male` / `female` / `other` | 性別篩選 |
| city | TEXT | `台北` / `台中` / `高雄` | 地區篩選 |
| occupation | TEXT | `工程師` / `設計師` | 職業搜尋 |
| education | TEXT | `大學` / `碩士` / `博士` | 學歷篩選 |
| height | INTEGER | `170` | 身高範圍篩選 (cm) |
| looking_for | TEXT | `friend` / `date` / `any` | 交友目的 |
| about_me | TEXT | `喜歡爬山、攝影和咖啡` | 自我介紹自由文字 |
| interests | TEXT[] | `[爬山, 攝影, 咖啡]` | 興趣標籤（多對多） |

## 2. 搜尋/配對條件

### 篩選參數

| 參數 | 說明 |
|------|------|
| `gender` | 性別篩選（完全匹配） |
| `age_min` / `age_max` | 年齡區間（從 birthday 計算） |
| `city` | 城市篩選（LIKE 模糊） |
| `occupation` | 職業篩選（LIKE 模糊） |
| `education` | 學歷篩選 |
| `height_min` / `height_max` | 身高區間 |
| `looking_for` | 交友目的 |
| `tags` | 興趣標籤（AND / OR 邏輯，回傳至少匹配任一 tag 者） |
| `q` | 全文搜尋（about_me + occupation） |

### 排序方式

- 興趣匹配數（共同 tag 越多越前面）
- 最新更新時間
- 預設依興趣匹配數 DESC + 更新時間 DESC

## 3. CLI 指令規劃

```
sms4 profile set <user_id>              # 互動式設定/更新交友資料
sms4 profile show <user_id>             # 檢視特定使用者的交友資料
sms4 profile search                     # 搜尋配對對象（互動式條件輸入）
sms4 profile search --gender female --age-min 25 --age-max 35 --tags "爬山,攝影"
sms4 interest add <user_id> <tag>       # 新增興趣標籤
sms4 interest remove <user_id> <tag>    # 移除興趣標籤
sms4 interest list <user_id>            # 列出使用者的興趣標籤
```

### 輸出範例（search）

```
===== 配對結果 (3 人) =====
#1 愛麗絲 (@alice) · 30 歲 · 台北 · 工程師

   關於我: 喜歡旅行和攝影 📸

#2 鮑勃 (@bob) · 28 歲 · 台中 · 設計師
   興趣: 爬山, 咖啡        (匹配 2)
   關於我: 程式設計師 & 咖啡愛好者

#3 卡蘿 (@carol) · 27 歲 · 高雄 · 美食部落客
   興趣: 攝影               (匹配 1)
   關於我: 美食部落客
```

## 4. Web API 端點規劃

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/profiles/{user_id}` | 取得使用者交友資料 |
| PUT | `/api/profiles/{user_id}` | 更新交友資料 |
| GET | `/api/profiles/search` | 搜尋配對對象（Query params） |
| POST | `/api/interests` | 新增興趣標籤 `{user_id, tag}` |
| DELETE | `/api/interests` | 移除興趣標籤 `{user_id, tag}` |
| GET | `/api/interests/{user_id}` | 列出使用者興趣標籤 |

### search query params

```
GET /api/profiles/search?gender=female&age_min=25&age_max=35&city=台北&tags=爬山,攝影&q=旅行
```

## 5. 前端頁面規劃

### ProfilePage (`/profile/:id`)
- 顯示使用者的交友基本資料卡片
- 興趣標籤展示（可點選觸發搜尋）
- 「發送私訊」按鈕

### ProfileEdit (`/profile/edit`)
- 表單編輯所有交友屬性
- 興趣標籤輸入（新增/刪除）
- 預填現有資料

### MatchSearch (`/search`)
- 篩選器面板（性別、年齡區間、城市、興趣標籤等）
- 結果列表（顯示使用者卡片 + 匹配度）
- 按匹配數排序

### Layout 更新
- 底部導航加入第四項：「配對」（🔍）或「探索」

## 6. 資料庫遷移

由於是增量開發，無需破壞性變更：

1. 執行 `CREATE TABLE IF NOT EXISTS profiles (...)` — `db.sql` 加入兩張新表
2. 執行 `CREATE TABLE IF NOT EXISTS interests (...)` + index
3. `db::init_db()` 加入新表建立語句
4. 現有使用者的 `profiles` 資料為 NULL（可後續補填）
