# SMS4 v1.5 — 影音嵌入

## 新增功能

貼文內容中的影音網址會自動偵測並嵌入可播放的元件：

### 支援的嵌入類型

| 類型 | 範例網址 | 前端元件 |
|------|----------|----------|
| YouTube | `https://youtube.com/watch?v=XXX` / `https://youtu.be/XXX` | iframe 16:9 播放器 |
| Vimeo | `https://vimeo.com/12345` | iframe 16:9 播放器 |
| 影片 | `https://example.com/video.mp4` | `<video>` 標籤 |
| 音訊 | `https://example.com/audio.mp3` | `<audio>` 標籤 |
| 一般網址 | 其他 URL | 藍色可點選連結（另開分頁） |

### 實作檔案

- `web/src/components/PostContent.tsx` — 純前端元件，無後端或資料庫變更
- 套用位置：`PostCard.tsx`（時間軸、貼文詳情、使用者頁面）及 `GroupDetail.tsx`（社團貼文）

### 設計要點

- URL 解析使用正規表達式，支援常見網域與副檔名
- 嵌入元件點擊時停止事件傳遞，不觸發貼文頁面導航
- YouTube/Vimeo 使用官方 embed 網址，含完整 iframe permission
- 影片與音訊使用 HTML5 原生標籤，設定 `preload="metadata"` 節省頻寬
- 不修改資料庫 schema，不影響後端
