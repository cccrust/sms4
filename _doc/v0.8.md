# SMS4 v0.8 — 前端登入/註冊/認證流程

實作前端 SPA 的登入、註冊頁面與 token-based 認證管理。v0.7 的後端 API 現在有前端 UI 對接。

## 2. 流程

```
未登入 → /login → 輸入帳號密碼 → 登入成功 → 跳回首頁 (/)
                → 點「註冊」→ /register
未登入 → /register → 輸入資料 → 註冊成功 → 跳回 /login
已登入 → 點「登出」→ token 清除 → 跳回 /login
已登入 → 直接存取任何受保護路由 → 正常顯示
未登入 → 存取受保護路由 → 自動跳轉 /login
```

---

## 3. 認證機制

- Token 儲存於 `localStorage`（key: `sms4_token`）
- 每次 API 請求自動帶入 `Authorization` header
- `AuthContext` 提供 `login()` / `register()` / `logout()` / `user` / `token` / `isAuthenticated`
- 登出時同時呼叫後端刪除 session + 清除前端 token

## 4. 建置與執行

```bash
cd web && npm run build       # 前端建置
sms4 web                      # 啟動後端（含前端靜態檔案服務）
# 或開發模式
sms4 web --dev --port 8080    # 僅後端 API，前端用 npm run dev
```

前端開發模式 `npm run dev` 透過 Vite proxy 將 `/api` 請求導向 `http://127.0.0.1:8080`。

## 5. 頁面樣式

維持現有暗色主題風格：
- 純黑背景、灰色邊框、白色文字
- 登入/註冊頁面居中卡片式佈局
- 錯誤提示以紅底紅框顯示
- 密碼欄位隱藏輸入
- 表單驗證（必填、密碼長度、密碼確認）
