# SMS4 v0.1

Rust + SQLite 打造的手機社群 CLI 工具（Threads 風格）。

## 技術棧

- **語言:** Rust (edition 2021)
- **資料庫:** SQLite (via rusqlite, bundled)
- **CLI 框架:** clap (derive 模式)
- **日期處理:** chrono
- **序列化:** serde / serde_json
- **錯誤處理:** anyhow
- **輸出著色:** colored

## 資料庫結構 (4 張表)

| 表名 | 說明 |
|------|------|
| `users` | 使用者帳號 (username, display_name, bio, avatar) |
| `posts` | 貼文 (user_id, content, parent_id, likes_count, replies_count) |
| `follows` | 追蹤關係 (follower_id, followee_id, UNIQUE) |
| `likes` | 按讚記錄 (user_id, post_id, UNIQUE) |

- `posts.parent_id` 支援回覆機制：`NULL` 為原貼文，非 `NULL` 為回覆
- 按讚與回覆數量透過 `likes_count` / `replies_count` 快取，避免每次 COUNT

## CLI 指令

### 初始化

```
sms4 init
```

建立 `sms4.db`（可透過環境變數 `SMS4_DB` 自訂路徑）。

### 使用者管理

```
sms4 user add <username> <display-name> [--bio]
sms4 user list [--search]
sms4 user get <id>
sms4 user update <id> [--display-name] [--bio]
sms4 user delete <id>
```

### 貼文管理

```
sms4 post add <user-id> <content>
sms4 post reply <post-id> <user-id> <content>
sms4 post list [--user-id] [--limit] [--offset]
sms4 post get <id>
sms4 post timeline <user-id> [--limit] [--offset]
sms4 post delete <id>
```

- `post list` 列出所有原貼文（不含回覆），依時間倒序
- `post get` 顯示單篇貼文 + 所有回覆
- `post timeline` 顯示指定使用者及其追蹤對象的貼文（社群時間軸）

### 追蹤管理

```
sms4 follow add <follower-id> <followee-id>
sms4 follow remove <follower-id> <followee-id>
sms4 follow followers <user-id>
sms4 follow following <user-id>
```

- 不能追蹤自己（回傳錯誤訊息）
- 重複追蹤自動忽略（INSERT OR IGNORE）

### 按讚管理

```
sms4 like add <user-id> <post-id>
sms4 like remove <user-id> <post-id>
```

- 重複按讚自動忽略（INSERT OR IGNORE）
- 取消讚時 `likes_count` 不會低於 0

## 使用範例

```bash
# 初始化
sms4 init

# 建立使用者
sms4 user add alice 愛麗絲 --bio "旅行攝影愛好者"
sms4 user add bob 鮑勃 --bio "程式設計師"

# 發布貼文
sms4 post add 1 "今天天氣真好！"
sms4 post add 2 "Rust 真好玩"

# 回覆貼文
sms4 post reply 1 2 "對啊，陽明山很漂亮"

# 追蹤
sms4 follow add 1 2

# 按讚
sms4 like add 2 1

# 檢視時間軸（自己 + 追蹤對象的貼文）
sms4 post timeline 1

# 檢視單篇貼文（含回覆）
sms4 post get 1
```

## 建置

```bash
cargo build --release
```

執行檔位於 `target/release/sms4`。

## 測試

```bash
cargo test                    # 單元測試（10 項）
bash case1.sh                 # 整合測試腳本
bash seed.sh                  # 填入大量假資料
```

測試腳本支援 `SMS4` 環境變數覆寫二進位路徑（預設 `cargo run --`）。
