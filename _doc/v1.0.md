# SMS4 v1.0 — 完整社群平台

Rust + SQLite + React 的手機社群軟體（Threads 風格），具備 CLI 與 Web 雙介面。

---

## 1. 技術棧

| 層級 | 技術 |
|------|------|
| 後端語言 | Rust (edition 2021) |
| 資料庫 | SQLite（rusqlite bundled） |
| CLI 框架 | clap (derive) |
| Web 框架 | axum 0.8 + tokio + tower-http |
| 前端 | React 19 + TypeScript + Vite + Tailwind CSS 4 |
| 密碼 | bcrypt |
| Token | UUID v4 |
| 輸出著色 | colored（支援 `NO_COLOR`） |

---

## 2. 資料表

| 表名 | 說明 |
|------|------|
| `users` | 使用者（含 `password_hash`） |
| `posts` | 貼文（`parent_id` 支援回覆） |
| `follows` | 追蹤關係（UNIQUE） |
| `likes` | 按讚記錄（UNIQUE） |
| `messages` | 私訊（`read` 標記未讀） |
| `profiles` | 交友資料（與 users 一對一） |
| `interests` | 興趣標籤（UNIQUE, NOCASE） |
| `sessions` | 登入 session（UUID token） |

---

## 3. CLI 指令

```
sms4 init                              # 初始化資料庫
sms4 auth register <u> <pwd> [--name]  # 註冊
sms4 auth login <u> <pwd>              # 登入
sms4 auth logout <token>               # 登出
sms4 user add <u> <name> [--bio] [--password]  # 建立使用者
sms4 user list [--search]              # 列出使用者
sms4 user get <id>                     # 檢視使用者
sms4 user update <id> [--display-name] [--bio]  # 更新
sms4 user delete <id>                  # 刪除
sms4 post add <user_id> <content>      # 發布貼文
sms4 post reply <post_id> <user_id> <content>  # 回覆
sms4 post list                         # 列出貼文
sms4 post get <id>                     # 檢視貼文（含回覆）
sms4 post timeline <user_id>           # 時間軸
sms4 post delete <id>                  # 刪除
sms4 follow add <follower> <followee>  # 追蹤
sms4 follow remove <follower> <followee> # 取消
sms4 follow followers <user_id>        # 粉絲列表
sms4 follow following <user_id>        # 追蹤中
sms4 like add <user_id> <post_id>      # 按讚
sms4 like remove <user_id> <post_id>   # 取消
sms4 msg send <sender> <receiver> <content>  # 私訊
sms4 msg conversations <user_id>       # 對話列表
sms4 msg messages <u1> <u2>           # 對話內容
sms4 profile set <user_id> [--params]  # 交友資料設定
sms4 profile show <user_id>            # 檢視
sms4 profile search [--filters]        # 搜尋配對
sms4 interest add <user_id> <tag>      # 興趣標籤
sms4 interest remove <user_id> <tag>
sms4 interest list <user_id>
sms4 web [--port] [--host] [--dev]     # 啟動 Web 伺服器
```

## 4. Web API

| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | `/api/auth/register` | 註冊 |
| POST | `/api/auth/login` | 登入（回傳 token） |
| POST | `/api/auth/logout` | 登出 |
| GET/POST | `/api/users` | 列表 / 建立 |
| GET/PUT/DELETE | `/api/users/{id}` | 讀取 / 更新 / 刪除 |
| GET | `/api/users/{id}/timeline` | 時間軸 |
| GET | `/api/users/{id}/followers` | 粉絲 |
| GET | `/api/users/{id}/following` | 追蹤中 |
| GET/POST | `/api/posts` | 列表 / 建立 |
| GET/DELETE | `/api/posts/{id}` | 檢視（含回覆）/ 刪除 |
| POST | `/api/posts/{id}/reply` | 回覆 |
| POST/DELETE | `/api/follow` | 追蹤 / 取消 |
| POST/DELETE | `/api/likes` | 按讚 / 取消 |
| POST | `/api/messages/send` | 傳送私訊 |
| GET | `/api/messages/{uid}/conversations` | 對話列表 |
| GET | `/api/messages/{uid}/{other}` | 對話內容 |
| GET | `/api/messages/{uid}/unread` | 未讀數 |
| GET/PUT | `/api/profiles/{uid}` | 交友資料 |
| GET | `/api/profiles/search` | 配對搜尋 |
| POST/DELETE | `/api/interests` | 興趣標籤 |
| GET | `/api/interests/{uid}` | 興趣列表 |

## 5. 前端 SPA 路由

| 路徑 | 頁面 |
|------|------|
| `/login` | 登入 |
| `/register` | 註冊 |
| `/` | 時間軸（貼文列表 + 發布表單） |
| `/messages` | 私訊對話列表 |
| `/messages/:id` | 對話內容 |
| `/users` | 使用者列表（可搜尋） |
| `/users/:id` | 使用者個人頁（含貼文、追蹤、私訊） |
| `/profile/:id` | 交友檔案（含基本資料、興趣、追蹤、私訊） |
| `/profile/edit` | 編輯交友資料 |
| `/search` | 配對搜尋 |
| `/posts/:id` | 貼文詳情（含回覆） |

## 7. 建置與執行

```bash
# 建置
cargo build --release          # 正式版 (target/release/sms4)
cd web && npm run build        # 前端建置

# 初始化 + 種子資料
sms4 init
bash seed.sh                   # 15 使用者 + 密碼 + 貼文 + 交友資料

# 啟動
sms4 web                       # 生產模式（含前端靜態檔案）
sms4 web --dev                 # 開發模式（僅 API，前端用 npm run dev）

# 環境變數
SMS4_DB=/path/to/db.db         # 自訂資料庫路徑
```

種子資料登入帳號：`alice` / `bob` / `carol` ... 密碼皆為 `<username>123`。
