# SMS4 v1.3 — 購物車與結帳流程

## 新增功能

### 資料庫
- **cart_items** 表：user_id, product_id, quantity, UNIQUE(user_id, product_id)

### 購物車流程
- 商場與商店頁面的「購買」改為「加入購物車」
- 購物車可調整數量、移除商品、顯示即時總金額
- 「結帳」按鈕將所有購物車項目轉為訂單、扣除庫存、清空購物車
- 導航列顯示購物車數量（5 秒自動更新）

### Web API
| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | `/api/cart` | 加入購物車（重複則累加數量） |
| GET | `/api/cart?user_id=:id` | 列出購物車 |
| PUT | `/api/cart/:id` | 更新數量 |
| DELETE | `/api/cart/:id` | 移除項目 |
| POST | `/api/cart/checkout` | 結帳（建立訂單 + 扣庫存） |
| GET | `/api/cart/count?user_id=:id` | 購物車商品總數 |

### 前端頁面
- **購物車** (`/cart`) — 新頁面，完整購物車操作
- **商場** / **商店頁面** — 按鈕改為「加入購物車」
- **導航列** — 加入「購物車 (N)」連結與即時數量
