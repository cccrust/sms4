# SMS4 v1.1 — 封鎖功能

新增使用者封鎖機制，封鎖後對方無法找到你的帳號、無法查看你的資料、雙方無法互傳私訊。

---

## 1. 資料庫

```sql
CREATE TABLE blocks (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    blocker_id INTEGER NOT NULL,
    blocked_id INTEGER NOT NULL,
    created_at TEXT NOT NULL DEFAULT (datetime('now')),
    FOREIGN KEY (blocker_id) REFERENCES users(id),
    FOREIGN KEY (blocked_id) REFERENCES users(id),
    UNIQUE(blocker_id, blocked_id)
);

CREATE INDEX idx_blocks_blocker ON blocks(blocker_id);
CREATE INDEX idx_blocks_blocked ON blocks(blocked_id);
```

---

## 2. 封鎖行為

| 情境 | 效果 |
|------|------|
| 使用者搜尋/列表 | 被封鎖者不會看到封鎖者的帳號 |
| 使用者個人頁 | 被封鎖者檢視回傳 404 |
| 傳送私訊 | 雙方互傳皆被拒絕 |
| 私訊列表 | 封鎖對象的對話不出現 |
| 私訊內容 | 雙方都看不到（回傳空陣列） |

---

## 3. CLI 指令

```
sms4 block add <blocker_id> <blocked_id>    # 封鎖
sms4 block remove <blocker_id> <blocked_id>  # 解除封鎖
sms4 block list <user_id>                    # 列出已封鎖使用者
```

---

## 4. Web API

| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | `/api/block` | 封鎖 `{ blocker_id, blocked_id }` |
| DELETE | `/api/block` | 解除封鎖 |
| GET | `/api/block/{user_id}` | 列出已封鎖 |
| GET | `/api/block/{user_id}/{other_id}` | 檢查是否封鎖 |
